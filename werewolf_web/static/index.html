第一次玩？两分钟规则

先连接模型、选择板子、关闭猜想模式。夜晚按私密提示行动；白天发言、比较声明、投票放逐。

全部狼人出局则好人胜；全部神职或全部平民出局则狼人胜。死者公开翻牌，警长放逐票重1.5票，平票无人出局。

不懂就问主持人，不消耗行动。女巫用药以本局规则为准。断线后可继续同一局；存档缺失或损坏时不保证恢复。
