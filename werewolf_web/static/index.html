推荐：在自己的 Agent 里玩

你在 Agent 对话里发言和行动，由 Agent 连接游戏。网页版是可选界面，不是核心体验。

给 Agent 的开局说明

当前可由支持本地终端和持续交互进程的 Agent 转接；尚无通用 Agent 插件或 MCP 接入。不会迁移当前网页对局。

安装说明
网页版 · 开局设置

所有正式入口共用 LLM 决策玩家，不限定 Agent 品牌。先配置模型连接、选择板子；模型预检通过后再发身份。离线仅供规则测试。

名字与人格

每位NPC可选每局随机或固定人格；开局后锁定。

模型设置

当前仅文字驱动。语音与视觉玩法尚无方案、尚未实现；头像仅作装饰。猜想模式要求双表并保留公开历史，不等于完美推理。
