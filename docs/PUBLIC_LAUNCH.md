# Public project scope

This is an experimental text-driven local Werewolf game and research environment.
It supports English and Chinese, conversational and browser interfaces. Normal
play requires a configured model connection; offline mode is an explicit rule-flow
test. Voice and behavioral visual input are not implemented.

Contribute reusable source and synthetic tests through pull requests. Follow the
[publication policy](PUBLIC_RELEASE.md), [asset scope](ASSETS.md) and
[security limits](../SECURITY.md). Actual sessions and development audit logs
remain local. Check GitHub Actions for the exact revision being released.
