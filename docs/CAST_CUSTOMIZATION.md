# Random personalities and editable names

See [the personality inventory and behavior limits](PERSONALITIES.md) for the
eleven presets and exactly what randomization does and does not change.

By default each new ordinary game independently randomizes NPC preset personalities,
display names, seats and hidden roles. Names are sampled without replacement
from the existing localized name pool, not generated by a model. All eleven NPC
presets are used once per match when all slots are random; the human player is not assigned AI behavior.
Each NPC can instead select a fixed preset before play, including duplicate
fixed presets. Unfixed slots draw from the remaining presets without replacement.
Randomization can coincidentally retain an earlier assignment.

The stable player ID, preset personality ID, display name and hidden game role
are separate. Renaming does not change personality, catchphrases, role assignment
or portrait. English personality text and catchphrases follow the assigned
preset, while behavior uses the same canonical profile in both languages.
Portraits still follow stable player IDs; randomized avatars are not implemented.
Preset prose references are rebound to this match's display names.

## Web

Open **Names & personalities** before starting:

- Use **Randomize names** to replace the complete cast's names.
- Edit any NPC name or **You** directly.
- Select a fixed preset or **Random each game** separately for each NPC.
- Start the game. Names remain locked for that match, so archived statements and
  ballots keep a consistent referent. Settings can be edited again after it ends.

Changing the setup language regenerates names from that language's pool and
replaces edits in the setup form. Names currently in the form are preserved when
starting another game; use the randomize button for a fresh cast of names.
No names or configuration are written to browser storage.

## Conversation / terminal

Names are random by default, with matching presets randomized independently:

```sh
python -m werewolf_web.chat_game --offline --lang en --name Shawn
python -m werewolf_web.chat_game --list-cast
python -m werewolf_web.chat_game --offline --name Shawn --rename dashan=River
```

Repeat `--rename PLAYER_ID=NAME` to edit multiple NPC names before play. The
stable IDs printed by `--list-cast` identify configuration slots, not presets or
hidden roles. `--seed` reproduces the same assignment. Changing only names or
locale does not consume the role/seat random stream or change role assignment.

The shared session accepts `names: {player_id: display_name}`. Omitted entries
receive random names avoiding any custom-name collision. `/api/cast` returns a
localized random preview; `/api/start` accepts the same mapping. Invalid names
return HTTP 422 before a game is registered.

## Boundaries

Names must be unique after Unicode normalization and case folding, 1–24
characters long, and contain a letter. Letters, combining marks, numbers,
spaces, hyphens, apostrophes and middle dots are accepted. Control characters,
markup, file separators, and host/system impersonation names are rejected.
Display names are escaped when rendered and never used to locate persona files.

Saved cognitive growth follows the trusted slot-plus-preset IDs within the existing memory
scope, not a display name. Legacy display-name memory files are left untouched
and are no longer used as the active adapter's fallback.

The old single-day shadow protocol remains unchanged in scope. The new
[extreme experiment](EXTREME_EXPERIMENT.md) adds explicit endpoint profiles to
complete seven-seat research games. [Playable conjecture beta](GAME_MODES.md)
is a separate local-strategy adapter.
