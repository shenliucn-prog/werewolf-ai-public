# Post-game night review / 赛后夜间复盘

After normal game over, the shared session publishes resolved night targets
(knife, guard, checks, potions and special night abilities) and engine death
causes. The browser log, review transcript and Agent/CLI output share this
deterministic narration. It is not a model's reconstruction.

The audit is private until game over, saved atomically with night settlement
and excluded from live public recovery views and NPC observations. Prompted
post-death guns remain in the public transcript, not this settlement audit.
Older saves start with an empty audit: only subsequently recorded nights can
be shown, and absent history must not be inferred.

Models receive up to two bounded excerpts of their own recent public statements
alongside existing decision memory and votes. Instructions emphasize faction
victory, reasons for changed stances and rescue likelihood versus exposure.
They do not prescribe wolf sacrifice, targets or replacement decisions.
No extra model calls or provider changes are introduced. Automated tests verify
data contracts and secrecy, not improved win rates or live model quality.

模型补充本人最近两条发言片段，强调阵营目标、改票依据与暴露成本；不强制倒钩、
不程序代打、不增加调用。自动化通过不等于已验证实战策略提升。
