推荐先在 GitHub fork 本仓库，再将自己的 fork 克隆到本机。文字和网页都在本机运行。
按下文安装依赖后，运行 `python -m werewolf_web.setup --lang zh-CN`：
引导检查环境、解释入口与费用、选择板子、身份、人格、名字和猜想模式，

不会提交当前行动。自然语言查询可用 `?把上一轮的票型拿出来`；网页使用主持人
问答框。放逐投票新增 `平安日`，警上发言结束后可以 `退警` 或 `不退警`。
平安日是实验性规则，计票已验证，但胜率平衡尚未验证。

## 快速开始

**推荐在自己的 AI Agent 对话里玩**：玩家对 Agent 发言、提问和行动，由 Agent 连接游戏，不是要求玩家直接操作终端。当前可通过有本地执行能力、能持续保留交互进程的 Agent 转接；尚未提供通用 Agent 插件或 MCP 接入，也未验证所有 Agent 产品。详见[Agent 游玩说明](docs/AGENT_PLAY.md)。网页版为可选界面。

需要 Python 3.10 或更新版本。从仓库根目录运行：

```bash
git clone https://github.com/shenliucn-prog/werewolf-ai-public.git
cd werewolf-ai-public
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r werewolf_web/requirements.txt
```

Windows PowerShell 改用 `.venv\Scripts\Activate.ps1` 激活环境。
玩游戏无需 Node；只有开发检查与前端测试需要 Node.js 24.15+（24.x）。

### 在 Agent 里玩（推荐体验）

让 Agent 阅读仓库与 [Agent 游玩说明](docs/AGENT_PLAY.md)，启动游戏，并在当前对话里转述发言和等待你的决定。它应连接实际游戏进程，而不是自行编造或模拟一局。

### 终端桥接入口：供 Agent 调用或手动测试

以下命令由具备持续终端交互能力的 Agent 运行；也保留给想手动测试的人。默认使用本机已登录的 Codex，由模型直接决定 NPC 发言、投票、上退警和技能行动，会消耗账户用量；不再只润色台词。

```bash
python -u -m werewolf_web.chat_game --lang zh-CN
# 英文版：
python -m werewolf_web.chat_game --lang en
```

未指定板子时先选板子，发身份前必须验证真实模型连接；失败不静默降级。
模型默认 `gpt-5.6-terra / medium`，可用 `--model`、`--effort` 为本局设置。
默认最多 240 次调用（含预检），`--max-model-calls` 可调整，最高 1000；单次超时 180 秒。
每次模型决策可能等待数十秒。需要支持当前隔离和结构化输出参数的 Codex CLI；不支持会明确失败，不自动安装或改全局配置。
`--offline` 仅用于明确选择的规则流程测试；`--backend legacy` 是旧的本地决策加可选台词润色。
Codex 普通模式尚未接入猜想表，选择猜想模式会明确停止，而不会偷换成旧策略。

开局前可以选自己的身份：网页使用“你的角色”，聊天加 `--role seer`；
默认仍随机。用 `--board classic --list-roles` 查看当前板子的可选身份。
选角不会改变角色总数，也不会公开其他人的身份。详见[游戏设置](docs/GAME_MODES.md)。
下一轮发明新玩法的准备见[研究实验台](docs/MECHANICS_LAB.md)，与普通模式隔离。

对话模式会逐条显示主持人播报、NPC 发言、插话和你的私密信息；轮到你时直接输入发言，
或使用明确动作如“投 3 号”“救 3”“毒 4”（原有板子的女巫不能同夜用两瓶药；神女巫双开板可输入“救 3 毒 4”）。任何行动等待期间都可输入 `?女巫怎么用药？`
向主持人私下问规则，不消耗行动。它与 Web 共用 `GameSession`、规则引擎和公开事件账本；
网页版目前仍是旧规则驱动 NPC，尚未接入 Codex 决策，不能视为同等推理体验。

### 中文 / English

网页开局前可选择中文或 English；对话模式用 `--lang zh-CN` 或 `--lang en`。
语言在开局时固定，适用于角色名字、人设口头禅、主持人、规则单聊、行动提示、系统消息和复盘。
NPC 的稳定身份、行为参数、认知能力和规则不会因翻译而改变；头像与跨局记忆按稳定身份关联。
英文玩家公开声明（例如 `I am the Seer. I suspect #3.`）也会进入 NPC 的公开观察。

To play in English, select **English** before starting in the browser, or run:

```bash
python -m werewolf_web.chat_game --lang en
```

Type your statement when invited to speak. Use `yes` / `no` to run for sheriff,
`vote 3` to vote, `choose 3` for a night target, or `pass` to skip an optional action.
On original boards the Witch uses `save 3` **or** `poison 4`; the experimental
`divine_witch_dual` board also accepts `save 3 poison 4` together.
At any action prompt, type `?How does the Witch work?` to ask the host privately
without consuming your turn. The host explains rules but does not choose targets for you.

旧 API 表达路径仅润色既定意图，可在失败时回退本地表达。Codex 路径则直接决策，失败、超时、非法输出或额度耗尽时停止对局，不替换为离线玩家。暂不支持断线续局。
旧的 `cli_game` 是含私密推理的中文开发观察入口；面向玩家的双语文本入口是 `chat_game`。

验证：`python3 -m unittest discover -s tests -q`。回归包含 10 种板子 × 两种语言 × 两种模式的
40 场完整离线对局矩阵，另有选角、特殊技能、英文行动和开局异常检查。
第一次玩请看[两分钟玩家指南](docs/PLAYER_GUIDE.md)；开发者请看[架构与扩展指南](docs/ARCHITECTURE.md)。

本仓库只包含通用玩法说明与合成测试，不发布实际对局记录、玩家记忆或本地实验结果。

### Web（可选）：对话为中心的辅助界面

发言记录与当前操作占据主区域；身份、紧凑的玩家名单放在左侧，规则单聊可按需展开。窄屏先展示对话，再展示辅助信息。成功开局后设置自动收起。两种入口不能迁移正在进行的对局，切换需要新开一局。

这是本机开发原型，请优先使用 classic 板子。特殊身份的实现范围和服务部署限制见 [已知限制](docs/KNOWN_LIMITATIONS.md)。

```bash
python -m uvicorn werewolf_web.run:app --host 127.0.0.1 --port 8000
# 打开 http://127.0.0.1:8000/
```

> 注意必须用包路径 `werewolf_web.run:app`。`run.py` 里是相对导入
> （`from . import config`），当成顶层模块跑会 `ImportError`。

## 推理引擎是怎么设计的

核心在 [`werewolf_web/ai/brain.py`](werewolf_web/ai/brain.py)。四个原则：

### 1. 一人一脑

每个 NPC 持有一个 `Brain` 实例：私有信念、私有日志、**私有随机源**。
任何两个 Brain 之间不共享状态。这是"各自思考"的物质基础——
不是给一个共享随机数取不同的台词模板。

### 2. 不开天眼

好人只能依据**公开信息**（发言/投票/翻牌）+ **自身私密信息**推理。
狼知道队友，但不知道好人的身份。预言家知道自己的验人结果，石像鬼知道查验结果。

### 3. 怀疑度 = 对数几率聚合 + 反向推理

这是最关键的一条。早期版本用线性加分，结果很荒谬：
一个人被 7 个人咬就 `+0.70` 直接打满，**狼队只要集体带票就能把一个好人钉死**，
连真预言家都被舆论裹挟着投了平民。

现在用 logit 累加（天然饱和）+ 按指控者的可信度加权：

```python
for w in 咬过他的人:
    logit += (0.5 - 我对咬人者的可疑度) * 0.80
```

咬人者越像狼，被咬的人越干净——**狼踩谁，谁反而更像好人**。
一个可信的人咬是弱信号，三个可信的人咬才是强信号。

硬信息优先级最高：自己亲手验过的直接定性，舆论动摇不了。

### 4. 可解释

每次决策都产出 `reason`（内心推理），CLI 里逐条打印，旁观者能看清"他为什么这么想"。

### 狼队：各自提案，再收敛

不是"狼王独断"。每只狼独立评估威胁（掺入各自的私有怀疑度与个人直觉），
各自提案后再多数收敛，平票听最激进的那只。所以狼之间会真实分歧：

```
  🐺 狼队刀人 —— 4 只狼各自提案
     1号夜枭（bluff）    → 提议刀 1号（自刀做银水骗解药）
     5号细草（undercover）→ 提议刀 7号
     6号阿蛮（undercover）→ 提议刀 2号
     ⚖️ 收敛：2号×2，7号×1，1号×1 → 统一刀 2号
```

分工上只允许**一个**悍跳位（队里最能演的那只），其余划水或深水——
两只狼同时跳预言家是互相拆台，送人头。

## 个性系统

12 个人有 5 种**论证风格**，从人设档案自动提取：

| 风格 | 行为 | 谁 |
|:---|:---|:---|
| `logic` | 摆证据、讲推导："X 保过 Y，Y 已翻牌是狼，**所以** X 有问题" | 阿蛮 |
| `gut` | 凭直觉："**我就觉得**是他，**说不上来为什么**" | 大山·夜枭·小鹿·甜豆·老麦 |
| `both` | 两面看再下结论："这个事情嘛，**要从两面看**……**不过综合下来**" | 阿墨 |
| `probe` | 追问依据："**等一下**——这个点你怎么解释？" | 细草·阿吉 |
| `plain` | 平铺直叙 | 阿岚·小满·阿承 |

关键是 `_why_suspect()` 让每个人说出**自己的依据**，依据取自他自己的观察日志。
所以同一个结论，12 个人 12 种说法；而两个角色也可能独立得出同一个正确推断。

## 智能与成长系统

人格回答“这个人倾向怎么做、怎么说”，智能回答“这个人能看懂多少、能推演多深”。
两者分开建模。每个角色都有独立认知档案：证据处理、递归推演、社交读取、欺骗、
校准、决断和学习率，并拥有 `preferred_depth` 与 `max_depth`。

- 高智能角色最多可进行 5 层推演，但证据接近时可能因为挑战第一判断而过度思考。
- 低智能角色推演较浅，却可能凭直觉、经验或更快的决断击中正确答案。
- 每次投票都保存信念、候选方案、效用、实际推演深度和过度思考标记。
- 赛后成长读取决策轨迹：胜利时强化校准；失败时区分证据不足与想得过多，做小幅、
  有上限的参数调整，而不是简单“赢了就变聪明”。

### 局内状态：状态波动，但不削弱基本功

每局开始时每个 NPC 都会获得一个可复现（由该局随机种子决定）的短期状态：状态、
情绪、压力、信心和动量。它会轻微改变投票/夜间行动面对接近选项时的噪声、推演深度
和表达语气；被点名、被维护，以及自己的判断被翻牌证实或证伪时，也只产生小幅反应。

这不是额外信息，更不会改写角色的长期认知档案：有效认知能力始终不低于基础能力的
82%，所有行动仍只读合法的公开和个人私有信息。每份投票与夜间决策轨迹都会带当时的
状态快照，供赛后教练复盘。Web NPC 记忆只保存一个有上限的跨局状态 carry，长期认知
与局内情绪严格分开；CLI 的上帝视角会在座位表中显示简短的“状态/情绪”。

CLI 与 Web 都调用同一个 `Brain`。Web 的 LLM 只负责把既定战略意图表达得更自然，
不能擅自改变跳身份、踩人、保人、投票或夜间行动。

主持人也有独立人格、技能与成长记录，但权限严格拆开：裁判只执行既定规则，导演只看
公开状态并控制节奏，教练只在赛后读取完整对局复盘。进行中的主持人不能临时发明引擎
没有执行的规则。

## 接 LLM（可选）

默认跑**离线推理引擎**，不依赖任何 API。想让 AI 更强：

```bash
cp werewolf_web/.env.example werewolf_web/.env
# 填入 LLM_API_KEY（OpenAI 兼容接口）
```

配了 Key 之后，**每个角色仍是各自独立调用 LLM**，思路不共享——
不会变成一个人用 12 张嘴说话。

本节描述的是旧 API 表达路径（网页版或 `--backend legacy`），不是默认 Codex 决策路径。
在旧路径中模型服务只是“表达层”：投票、夜间行动、规则结算与胜负仍由本地策略/规则引擎锁定。
每局会冻结当前模型配置；调用超时、额度耗尽、返回空内容或连续失败时，自动改用本地
表达继续游戏。`LLM_TIMEOUT_SECONDS` 和 `LLM_GAME_MAX_CALLS` 可控制等待时间与成本。
推理强度只会在服务商明确支持且配置了 `LLM_REASONING_PARAM` 时才发送，普通兼容接口
不会收到不兼容字段。托管版可在 `POST /api/start` 的 `llm` 对象中传入一次性的同名配置；
API Key 不会出现在 SSE、复盘、记忆或状态接口中。

Web 顶部的“模型设置”可选“使用服务器默认”“只用本地 AI”或“本局自带 Key”。自带 Key
只随本次开局请求发送，随后会从页面输入框清除；每个 Web 对局也使用独立的会话与 NPC
记忆目录，不会与其他玩家混用模型配置或跨局状态。

### 不熟规则？随时单聊主持人

Web 右侧的“问主持人（规则单聊）”可在任何阶段使用，不会占用发言、投票或夜间行动。
主持人只根据当前板子的公开规则和公开流程答疑，例如身份技能、胜利条件、昼夜顺序和
投票规则；它不会读取未公开身份、夜间结果或 NPC 私密状态，也不会替玩家判断谁是狼、
该投谁或该使用哪个夜间目标。

### 更像真实牌桌的自由插话

Web 对局的白天主发言后，NPC 可能围绕公开的质疑、维护或跳身份主动插话；被打岔者可简短回应，
而所有插话都会被全桌听见并写入同一事件账本。主持人只根据公开的对话长度、发言分布和
重复拉扯决定是否放行下一句或收束话题，避免两个人无限对话。每人每天额外发言有上限，
整天的插话也有总预算；因此桌面会活起来，但投票不会被聊天淹没。

## 关于人物档案

12 个 AI 角色各有完整人格档案（性格画像 / 发言特征 / 游戏习惯），
已全部脱敏为虚构角色：大山、阿墨、阿岚、小满、夜枭、小鹿、阿蛮、甜豆、
细草、老麦、阿吉、阿承。公开前仍需核对历史提交、素材来源与图片元数据，检查记录见 [发布准备](docs/PUBLIC_RELEASE.md)。

想换人设就改 `werewolf_web/data/personas/player-*.md`。解析器会从「性格画像」整段提炼
行为参数（攻击性 / 逻辑 / 伪装 / 谨慎 / 话量 / 论证风格），
改完重新开一局即生效，不用动代码。

## 目录结构

```
werewolf_web/
  game/engine.py       # 规则引擎：角色分配、昼夜状态机、技能结算、胜负判定
  game/models.py       # Seat / GameEvent
  ai/brain.py          # 离线独立推理引擎（一人一脑）
  ai/strategy.py       # 信息集、信念、候选策略与决策轨迹
  ai/affect.py         # 有界的每局状态、情绪反应与跨局 carry
  ai/growth.py         # 独立认知档案、思考深度与赛后成长
  ai/strategic_agent.py # 对共享 Brain 的会话适配层
  ai/npc.py            # 人设解析与旧 Web Agent（兼容保留）
  ai/host.py           # 主持人：裁判/导演/教练边界、人格与成长
  ai/llm.py            # LLM 客户端 + 无 Key 时的降级
  cli_game.py          # 无 UI 的 AI 批量对局/回归
  chat_game.py         # 人类可参与的对话式入口
  run.py               # GameSession 核心事件流 + FastAPI/SSE Web 适配
  static/              # 前端（index.html / css / js / 立绘）
  data/boards.json     # 8 种原有板子 + 2 种神女巫实验板
  data/personas/       # 12 份角色档案（已脱敏）
```

> 对局跑出来的复盘记录、NPC 记忆、主持人风格都存在
> `werewolf_web/data/` 下对应目录，已 `.gitignore`，不会进仓库。

## 验证范围

完整对局矩阵覆盖 10 种板子 × 2 种语言 × 2 种模式，共 40 局，另有选角、特殊技能与私密信息边界的回归测试。
特殊技能已接入网页和聊天共用流程；动作时机见[本项目规则版本](docs/RULE_VARIANT.md)，边界与平衡仍以[已知限制](docs/KNOWN_LIMITATIONS.md)为准。收到白天技能提示时，可输入 `choose 3` 选择目标或 `pass` 跳过。

```bash
python -m unittest discover -s tests -q
node --check werewolf_web/static/js/app.js
node --check werewolf_web/static/js/i18n.js
npm ci
npm test
python scripts/check_release.py
```
